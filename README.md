# موقع دار روضة المحبين

موقع لدار تحفيظ القرآن الكريم: الخاتمون، الحفلات، الأخبار، ومساعد تعليمي ذكي — بتحديث فوري للبيانات.

## الملفات
- `index.html` — الموقع (HTML + CSS + JavaScript).
- `api/data.js` — خادم البيانات على Vercel (Redis / Upstash) مع التحقق من كلمة سر المشرف.
- `api/chat.js` — المساعد الذكي.
- `api/kb.js` — قاعدة معرفة موثوقة (تجويد، آداب، علوم القرآن).
- `dev-badge.js` — بطاقة المطوّر المنبثقة (تُفتح عند الضغط على شعار الموقع وتوصل للبروتوفوليو).
- `assets/` — الصور (`logo.jpg`، `art.jpg`، `dev-mazen.png`).

## المساعد الذكي — كيف يعمل
يعمل على ثلاث طبقات، بالترتيب:

1. **قاعدة معرفة موثوقة (بدون إنترنت)** — أسئلة التجويد والآداب تُجاب فورًا وبإجابات دقيقة ثابتة من `api/kb.js`.
2. **معلومات الدار** — أسئلة التواصل والمواعيد والعنوان والتسجيل والمعلمين والحلقات تُجاب مباشرةً من إعدادات الموقع (بلا شبكة، وبلا احتمال هلوسة).
3. **مزوّد ذكاء اصطناعي مجاني** — للأسئلة العامة، عبر `GROQ_API_KEY` أو `OPENROUTER_API_KEY` إن وُجدا، وإلا عبر Pollinations المجاني، ثم رد احتياطي عند تعذّر الاتصال.

المساعد يمرّر للذكاء الاصطناعي «معلومات الموقع» الحالية + قاعدة المعرفة كسياق (RAG)، فيلتزم بها ولا يخترع أحكامًا.

### أسئلة الدار
المساعد يجاوب عن الدار تلقائيًا من بيانات الموقع نفسها، فلا يحتاج المشرف لكتابة معظمها:

| السؤال | المصدر |
|---|---|
| «إزاي أتواصل مع الدار؟»، «رقم التليفون كام؟» | **أزرار التواصل** الظاهرة في الموقع (واتساب / فيسبوك / انستجرام / الخريطة) |
| «إيه مواعيد الحلقات؟»، «بتبدأ امتى؟» | حقل `hours` إن وُجد، وإلا يُستخرج من نص **الإعلانات/الأحداث** اللي فيها وقت |
| «عنوان الدار فين؟» | `address` + `location` |
| «إزاي أسجّل في الدار؟» | `register` |
| «مين المعلمين؟» | `teachers` |
| «إيه الحلقات والمراحل؟» | `classes` |
| «عن الدار ايه؟» | `about` |

- **التواصل** لا يُكتب يدويًا: المساعد يعرض نفس روابط أزرار التواصل الموجودة في الصفحة (والواتساب يُبنى من `phone` لو الرابط مش موجود).
- **المواعيد** تُقرأ من الإعلانات تلقائيًا إن لم تُكتب في حقل `hours`.
- **أسلوب الرد** ودود وبالعامية المصرية الخفيفة، وعند غياب معلومة يعتذر بلطف (مثل: «معرفش بصراحة يا صاحبي 🙈») ويوجّه المستخدم لأزرار التواصل بدل اختراع بيانات.

### (اختياري) تحسين الاستقرار بمفتاح مجاني
Pollinations المجاني يسمح بردّ واحد كل 45 ثانية، وهو مناسب للمواقع الصغيرة. لاستقرار أعلى، أضف مفتاح Groq المجاني:
1. سجّل في `console.groq.com` وأنشئ مفتاحًا.
2. في Vercel: Settings ← Environment Variables ← أضف `GROQ_API_KEY` بقيمته.
3. أعد النشر. سيُستخدم Groq تلقائيًا قبل Pollinations.

## بطاقة المطوّر (dev-badge)
مكوّن مستقل يعرض بطاقة تعريف بالمطوّر ورابط البروتوفوليو. لا يُضيف زرًا عائمًا؛ يُفتح برمجيًا عبر `window.openDevCard()`. في هذا الموقع تُفتح عند الضغط على شعار الدار في الشريط العلوي.

```html
<script>window.DEV_BADGE = { accent: "#d8b45e", portfolio: "https://my-protfolio-space.vercel.app/" };</script>
<script src="dev-badge.js" defer></script>
<script>document.querySelector('#brandBtn').addEventListener('click', () => window.openDevCard());</script>
```

الإعدادات المتاحة: `name`, `nameEn`, `role`, `note`, `avatar`, `portfolio`, `github`, `email`, `whatsapp`, `accent`.

## المساعد كزر عائم
المساعد ليس صفحة كاملة، بل زر عائم (`#chatFab`) يفتح لوحة تفاعلية (`#chatPanel`) من أي مكان في الموقع دون التمرير. يُفتح كذلك من بطاقة «المساعد» في الصفحة الرئيسية، ومن الرابط `#chat` مباشرة. الإغلاق بـ `Esc` أو بالضغط على الخلفية أو زر ✕.

## التشغيل
1. **البيانات:** أنشئ قاعدة Upstash Redis، ثم في Vercel أضف المتغيّرات:
   - `KV_REST_API_URL` و `KV_REST_API_TOKEN` (أو `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN`).
   - `ADMIN_PASSWORD` — كلمة سر لوحة الإشراف.
2. **النشر:** ارفع المستودع إلى Vercel (يتم اكتشاف `api/` تلقائيًا).
3. **الإشراف:** افتح الموقع واضغط مطوّلًا على نص المطوّر في الفوتر، ثم أدخل كلمة السر.

الصور: `assets/logo.jpg` (الشعار) و `assets/art.jpg` (الزخرفة) — استبدلهما بنفس الاسم لتغييرهما.
